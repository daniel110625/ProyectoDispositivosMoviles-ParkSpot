## Descripción del proyecto
ParkSpot es una aplicación móvil para la gestión y localización de parqueos.

La aplicación permitirá registrar, consultar, modificar y eliminar parqueos.
Los usuarios podrán visualizar los parqueos registrados mediante una
lista con filtros personalizados y consultar su ubicación mediante un mapa.

La aplicación también permitirá agregar fotografías de los parqueos utilizando
la cámara o la galería del dispositivo.

## Objetivo
Desarrollar una aplicación móvil sencilla que permita administrar
información de parqueos y facilitar la consulta de su ubicación y
características.

## Funcionalidades
### CRUD de parqueos
La aplicación permitirá:

- Registrar un parqueo.
- Consultar la información de un parqueo.
- Modificar la información de un parqueo.
- Eliminar un parqueo.

### Lista y filtros personalizados
Los parqueos podrán visualizarse mediante una lista y podrán filtrarse según:

- Tipo de vehículo: carro, moto o ambos.
- Tipo de parqueo: gratuito o de pago.

### Cámara y galería

Al registrar o modificar un parqueo se podrá agregar una fotografía utilizando
la cámara o seleccionando una imagen desde la galería del dispositivo.

### Dialog

Se utilizarán cuadros de diálogo para confirmar determinadas acciones, por
ejemplo, la eliminación de un parqueo.

### Mapa

Los parqueos registrados podrán visualizarse en un mapa mediante marcadores
según su ubicación.
